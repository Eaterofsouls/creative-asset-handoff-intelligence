01 The Problem

Every finished campaign leaves behind a folder like this one. A human eventually has to sit down and figure out, file by file, which of these is actually the deliverable.

This workflow automates the mechanical parts of that cleanup — hashing, dimension checks, duplicate detection, filename-pattern grouping — and keeps the genuinely uncertain calls visible to a person instead of guessing.

02 How It Works

Nine stages, orchestrated in n8n. deterministic steps measure things exactly. ai-assisted steps only run where a rule genuinely can't decide. human is the only thing with final authority.

01Input Project folder + optional expected-deliverables manifest.
02Discovery & Metadata deterministic Recursive scan, dimensions, duration/codec, SHA-256 + perceptual hash. One bad file never stops the batch.
03Duplicate & Version Analysis deterministic Exact hash matches + perceptual-hash near-duplicates + filename-pattern version clustering.
04AI Cluster Analysis ai-assisted Claude Sonnet (vision) reasons about ambiguous version families only — never asked to judge design quality, never trusted without a confidence score.
05Classification deterministic Weighted scoring combines filename signals, recency, manifest match, duplicate evidence, and AI confidence into one status per asset.
06Validation deterministic Format, dimensions, integrity, and manifest comparison — flags missing and invalid deliverables explicitly.
07Human Review human Anything uncertain surfaces in an n8n form: approve, reject, mark final, mark duplicate, exclude, or recategorize.
08Delivery Builder deterministic Copy-only packaging into delivery/<category>/. Source files are never deleted or moved.
09Manifest + Report deterministic delivery_manifest.(json|html) and processing_report.html, generated from the same asset ledger.

05 What This Is — and Isn't

This is a production-oriented n8n workflow for automating the operational cleanup and validation that happens after a creative campaign is completed. It is not an "AI-powered DAM," it does not claim fully autonomous delivery, and it does not claim perfect final-file detection. The system explicitly scores its own confidence and routes anything uncertain to a human. The creative professional retains final authority over every delivery decision — see docs/human-review.md and docs/limitations.md.
